# 今日のコーデ提案 👗

性別・シーン・季節・気温・時間帯・体型・年齢・人気系統などから、その日のコーディネートを提案するWebアプリです。全身イメージ（アイテム別アイコン＋着用イラスト）付きで、手持ちの服からの提案（マイクローゼット）や提案履歴にも対応しています。

**➡️ 公開ページ:** https://mricky0818-maker.github.io/fashion-app/

## 主な機能

- **多彩な条件から提案**：性別 / シーン（8種）/ 詳細な場所 / 系統（12種：韓国系・モード・Y2K など）/ 気温 / 季節 / 時間帯 / 好みの色 / 身長・体重・体型 / 年齢層（7段階）
- **系統ごとの「全身一式」提案**（性別・気温に対応）
- **わかりやすい表示**：アイテム別のアイコン＋色、体型を反映した着用イラスト
- **あなたに合わせたアドバイス**（体型・身長・年齢・場所別）
- **便利機能**：アイテム個別シャッフル / お気に入り / コピー / AI画像生成用プロンプト / 提案履歴
- **👕 マイクローゼット**：手持ちの服（写真）を登録し、その中からコーデを提案（カテゴリ・季節は複数選択可）
- **買い物・実例へのリンク**：ZOZOTOWN検索 / WEAR・Pinterest・Instagram
- ポップな見た目、ライト/ダークモード対応

## 使い方

上記の公開ページを開くか、`index.html` をブラウザで開くだけです。特別なインストールは不要です。

## プライバシー

登録した服の写真やお気に入り・履歴は、**利用者の端末内（ブラウザのlocalStorage）にのみ保存**され、外部サーバーには送信されません。買い物・SNS・実例のリンクを開くときだけインターネット接続を使います。

## 補足

提案の内容は、一般的なファッションの知識をもとに構成した静的データです。リアルタイムの流行や特定インフルエンサーの投稿とは連動していません。
